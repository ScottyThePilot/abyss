# Abyss

This is where all of my miscellaneous code and crate stuff goes
to be lost forever, found again only when I start that one random
project that *does* need it.

## Features

- Caching/Memoization helpers
- Error + Context helper type
- Error/Result printing/logging helper traits
- Opaque non-generational IDs
- Linear interpolation
- Iterator wrapper type macros
- `AsPtr` trait for generic pointer-wise equality checking
- Function for setting the CWD to the parent directory of the executable
